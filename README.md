# CraftMan — сайт барбершопу (Бердичів)

Односторінковий сайт на одному файлі `index.html`: HTML, CSS і JS без фреймворків і збірки.

## Структура

```
index.html        — сайт CraftMan
img/              — логотип, фото майстрів, прев'ю для соцмереж (og.jpg)
template/         — чистий шаблон для інших барбершопів і студій (демо «Гарт»)
```

## Як редагувати

Увесь вміст сайту — в об'єкті `CONFIG` на початку `<script>` у `index.html`:
контакти, графік, послуги й ціни за рівнями майстрів, майстри, тексти, договір оферти.
Детальна інструкція — коментарем на початку `template/index.html`.

## Заявки з форми запису

Зараз форма працює в демо-режимі. Щоб заявки надходили, заповніть у `CONFIG.booking`:
- `formsubmitEmail` — пошту (перша заявка надішле лист активації FormSubmit), або
- `telegram.botToken` і `telegram.chatId` — Telegram-бота.

## Публікація (коли власник погодить)

Settings → Pages → Source: **Deploy from a branch** → `main` / `/ (root)` → Save.
Через хвилину сайт буде на `https://kos09.github.io/craftman/`.
Після публікації вкажіть цю адресу в `CONFIG.seo.url` і в тезі `og:url` у `<head>`.
